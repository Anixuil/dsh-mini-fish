## 2. 最重要的规则：遮挡区要补画

图层会被旋转/位移，**它盖住的地方在下面一层必须画全**，否则一动就露洞：

| 被盖住的 | 要在哪层补 |
|---|---|
| 刘海/前发盖住的额头、眉毛位置 | `head.png` 补全额头与眉骨 |
| 后发盖住的脖子、肩膀 | `body.png` 补全 |
| 鲸尾盖住的裙摆/身体 | `body.png`、`skirt.png` 补全 |
| 耳朵盖住的后发 | `hair_back.png` 补全 |
| 手臂盖住的裙身 | `body.png` 补全 |
| 裙摆盖住的大腿 | `body.png` 补全 |
| 发箍/蝴蝶结盖住的头发 | `hair_front.png` / `hair_side_*.png` 补全 |

做法：PSD 里逐层隐藏，用修补/仿制把洞补上，再分层导出。

## 3. 导出规则

- PNG-24 带 alpha，sRGB；**不要**白底、不要拼合背景
- **不要**把阴影/发光烘焙进本体（阴影单独一层 `shadow.png`）
- 每张都是 1024×1328，**位置不能移动**（所有层共用同一张画布坐标）
- 边缘不要白边/灰边（导出前检查 matte；深色衣服尤其容易出白边）
- 眼睛高光可以包含在 `eyes_open.png` 里，也可以单独一层（单独一层将来能「眼神跟随」）
- 命名全小写 + 下划线，严格按上表

## 5. 我会拿这些素材做什么

1. 运行 `python tools/check-pet-pack.py` 自检尺寸、缺层、透明区，并生成棋盘格合成预览核对位置
2. 用 `rig.json` 绑定骨骼：尾巴/耳朵/头发/裙摆弹簧，眼睛/嘴型切换
3. 接入 DSH 信号：思考时敲键盘、工具成功比耶、回合结束放星星、报错垂耳
4. 打包成可导入的 `.dshpet`，并更新规范文档给其他作者用
