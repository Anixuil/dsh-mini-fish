# 给 GPT 的素材生产 Prompt（可直接复制）

## 使用说明

1. 新开一个对话，模型要有**图像生成/图像编辑**能力（GPT-4o / GPT-5 系列带 image tools 的都可以）；如果它还能**执行 Python**，效果最好（用于校验尺寸和叠图）。
2. 先把下面「复制开始 → 复制结束」整段发给它。
3. 同一条消息附上这 5 个文件：
   - `assets/ref-three-view.webp`（正面/侧面/背面三视图，主参考）
   - `assets/ref-sheet.png`（细节设定图：发箍、蝴蝶结、胸针、围裙刺绣、鞋）
   - `pets/_template-l1/canvas-guide.png`（1024×1328 画布辅助线）
   - `pets/whale-maid/parts/body.png`（当前透明立绘，姿态/线宽基准）
   - `docs/art-assets-checklist.md`（图层清单文字版）
4. 它先给**母版**，你验收母版（尺寸、姿态、画风）没问题后，再让它逐张做 P0 图层。
5. 拿回来的图直接放 `pets/whale-maid-l1/parts/`，我这边做抠白底、对齐、枢轴、绑定和打包。

> 关键设定：**不让它每次重新画整张**，而是「以同一张母版为输入，每次只提取/修改一个图层」。
> 这是唯一能让 20 多张图位置、比例、画风保持一致的做法。

## Prompt（复制开始）

```text
你是一名二次元游戏美术，现在要为一款 Windows 桌面宠物（DSH 桌宠）生产一套「可分层绑定」的角色素材。
我会给你角色设定图、细节图、画布辅助线、当前立绘，以及分层清单。

【角色】
DeepSeek 鲸鱼娘 Q 版女仆：深海蓝到浅青蓝渐变长发、头顶呆毛、横向展开的鲸鱼鳍状耳朵、
身后粗壮鲸尾、深蓝白女仆裙、白色蕾丝发箍、浅蓝双蝴蝶结、胸前深蓝领结+椭圆蓝宝石胸针、
白围裙上刺绣喷水小鲸鱼。三头身/二头身 Q 版，大脑袋、短身体。

【最终用途】
素材会切成透明 PNG 图层，绑定骨骼后做呼吸、眨眼、说话、尾巴摆动、耳朵轻颤、挥手等动画。
因此「每个图层的位置必须与母版严格一致」，不能重新构图。

【硬性画布规则】
- 画布固定 1024×1328 像素（竖版），sRGB，白色背景 #FFFFFF。
- 角色水平居中（身体中线 x=512），脚底贴画布底部（y≈1320），头顶呆毛上方留 30–40px 安全边。
- 尾巴向右伸展，最右不超过 x=1000；耳朵左右展开，不要裁切。
- 所有输出必须是同一姿态、同一位置、同一比例：A-pose，双臂自然下垂并略微外张，不遮挡裙身。
- 背景纯白：无渐变、无纹理、无地面、无投影、无边框、无文字、无水印、无棋盘格透明图案。
- 不要画角色名标签、色卡、辅助线、九宫格拼图。

【画风锁定】
- 日系 Q 版赛璐璐上色，两到三层阴影，线条粗细均匀。
- 线稿主色深藏青 #1B2B4A；头发渐变 #1C4A8F → #8FE3FF；女仆裙 #162447，蕾丝 #FFFFFF；
  眼睛蓝渐变；胸针椭圆蓝宝石；围裙刺绣小鲸鱼。
- 不要改设计：不要加帽子、围巾、武器、眼镜、额外配饰；保留发箍、双蝴蝶结、胸针、围裙刺绣、鞋。
- 柔光/高光不要跨部件边界（便于分层），不要大面积渐变光斑。

【工作流程（必须遵守）】
第 1 步：生成「母版」（MASTER）
  - 1024×1328 白底正面全身像，按上面的角色设定与画风。
  - 生成后如果尺寸不对，请用代码执行裁切/补白到 1024×1328。
  - 回复里明确写出母版的实际像素尺寸。

第 2 步：所有图层都从「母版」派生，禁止凭空重画
  - 每次只做一个图层：以母版为输入图，做一次局部编辑/抠层。
  - 编辑只允许改变「目标图层」相关像素，其余保持完全不变。
  - 不要以其他图层的输出为输入，永远回到母版。
  - 每次输出一张单独的 PNG，不要输出拼图/九宫格/多格对照图。
  - 无法直接生成透明底时，就输出白底 PNG，我会自己抠图；但必须是纯白背景。

第 3 步：图层提取的通用指令模板
  「以母版为唯一输入，做图层提取：把除【目标部件】以外的所有像素替换为纯白 #FFFFFF，
   只保留【目标部件】，并用同一画风把被其他部件遮住的部分自然补全。
   不改变画布尺寸、角色位置、比例、线宽、颜色；不重新构图；不新增元素；不加阴影/文字/水印。
   输出 PNG。」

第 4 步：P0 图层清单（先做这 11 张）
  文件命名严格使用下列英文名，全部 1024×1328、白底、单张输出：

  1) tail.png
     目标：完整的鲸尾 + 尾柄根部。
     补全：被裙摆、身体挡住的尾柄部分（想象尾巴从腰后延伸出来的完整形状）。
  2) ear_l.png
     目标：左侧鲸鱼鳍耳。
     补全：被后发、头部挡住的耳根连接处。
  3) ear_r.png
     目标：右侧鲸鱼鳍耳。
     补全：被后发、头部挡住的耳根连接处。
  4) ahoge.png
     目标：头顶呆毛。
     补全：呆毛与头顶/发箍连接处的根部（被发箍/刘海压住的部分）。
  5) hair_front.png
     目标：前发/刘海（含垂在额头前的发束）。
     补全：被发箍、呆毛、蝴蝶结压住的部分。
     注意：不要包含脸、眉毛、眼睛、额头皮肤。
  6) eyes_open.png
     目标：睁开的双眼（含瞳孔、高光、睫毛、眼线）。
     不包含：眉毛、腮红、嘴、脸、头发。
  7) eyes_half.png
     目标：同样的眼睛位置和大小，改为半闭眼（上眼睑下压、瞳孔被遮住约一半）。
     其余完全不变。
  8) eyes_closed.png
     目标：同样的位置和大小，闭眼（保留眼线和睫毛，闭眼弧线自然）。
     其余完全不变。
  9) mouth_smile.png
     目标：微笑的嘴（小嘴，含舌头/口腔颜色如设定）。
     不包含脸、腮红、下巴阴影。
  10) mouth_open.png
      目标：张嘴说话的口型（同样位置大小，嘴可略大）。
  11) mouth_surprised.png
      目标：惊讶的「O」形嘴（同样位置大小）。

第 5 步：P1 图层（P0 验收通过后，如果你还能继续，再做这些）
  统一用同一条提取模板，名称与补全要求如下：
  - shadow.png：脚下柔和椭圆阴影（半透明灰蓝，可单独一张，不要烘焙进其他层）。
  - hair_back.png：后发整片。补全：被头、耳朵、身体挡住的部分。
  - body.png：脖子+躯干+女仆裙上身+腿+鞋（不含裙摆、手臂、头、任何头发）。
    补全：被裙摆、手臂、尾巴、头挡住的部分（尤其大腿、腰后）。
  - skirt.png：裙摆+蕾丝边。补全：被围裙、手臂、尾巴挡住的部分。
  - apron.png：白围裙+小鲸鱼刺绣。补全：被手臂挡住的边缘。
  - brooch.png：胸前蓝宝石胸针。
  - arm_l.png：左臂（袖子+手）。补全：被身体/裙身挡住的肩部连接。
  - arm_r.png：右臂（袖子+手）。补全：同上。
  - head.png：头部皮肤+耳朵内侧+脖子衔接。补全：被刘海、发箍、耳朵挡住的额头/头顶/耳根；
    不包含五官、头发、发箍、蝴蝶结。
  - brow.png：双眉。
  - blush.png：腮红。
  - hair_side_l.png / hair_side_r.png：左右侧发束。补全：被脸、肩、发箍挡住的部分。
  - headdress.png：白色蕾丝发箍。补全：被蝴蝶结/呆毛挡住的部分。
  - bow_l.png / bow_r.png：左右浅蓝蝴蝶结。

【交付格式】
- 每张图单独一个文件，文件名与清单完全一致（小写+下划线）。
- 在回复末尾给我一个表格：文件名 | 实际尺寸 | 是否白底 | 是否补全遮挡 | 已知问题。
- 如果用了代码执行，请顺便检查：所有图尺寸都是 1024×1328；把图层按 tail→hair_back→body→skirt→…→bow_r
  叠一张合成图，确认没有错位；把检查结果写进表格。
- 最后附一段「风格说明」：主色 hex、线宽感受、阴影层数，方便后续保持一致。

【自检清单（每张输出前都过一遍）】
1. 尺寸是否 1024×1328？
2. 背景是否纯白、无棋盘格、无阴影、无文字？
3. 角色位置/比例/线宽是否与母版一致（可叠图检查）？
4. 是否只有目标部件，没有混入其他部件？
5. 被遮挡区域是否补全（不是留透明洞/白洞）？
6. 四边是否留安全边，呆毛/耳朵/尾巴没有被裁切？

【降级方案】
如果当前工具无法稳定做出「对齐的分层提取」，请明确告诉我，并优先交付：
1) 母版；
2) 闭眼/半闭眼/三种嘴型；
3) 尾巴、左右耳、呆毛、刘海 这 5 个部件。
宁可少而准，也不要 20 张位置对不上的图。
```

## 我这边会验收什么

拿回来后我会跑：

```powershell
python tools/check-pet-pack.py pets/whale-maid-l1
```

检查项：尺寸是否 1024×1328、是否缺层、每层 alpha 是否有内容、合成预览是否错位、遮挡补全是否有洞。
然后我负责：白底抠图→透明、画布对齐、枢轴微调、rig 绑定、弹簧动画、DSH 信号联动、打包。

**所以 GPT 的任务只有一个：把「同一张母版的各个部件」画准、画全、位置不漂。**
