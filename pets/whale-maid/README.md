# 蓝鲸女仆·小蓝 / Lapis, the Whale Maid

DSH 桌宠参考宠物包（L0 静帧 + 程序化动作）。

- 角色：DeepSeek 鲸鱼娘（吃白饭的蓝色大肥鱼）Q 版女仆形态
- 素材来源：用户提供的角色设定图（正面视图），已做背景透明化与裁切
- 授权：CC-BY-NC-4.0（仅限非商业同人使用；商业使用请联系角色作者）
- 形态：L0 —— 单张透明立绘；呼吸、重心摆动、上下浮动、视线跟随、拖拽倾斜、点击弹跳均由运行时程序化生成

## 如何替换成你自己的宠物

1. 画一张透明底立绘（PNG，建议高 800–1200px，人物脚底贴画布底边）。
2. 放到 `parts/body.png`。
3. 改 `pet.json` 的 `canvas.width / canvas.height` 为你图片的像素尺寸。
4. 重启桌宠即可。

进阶（L1 分层骨骼）规范见仓库 `docs/dsh-pet-feasibility.md`。
